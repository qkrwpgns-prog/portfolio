# inbox — 자료 넣는 곳

여기에 아무 형식으로나 자료를 넣고 Claude에게 **"inbox 정리해줘"** 라고 말하면 됩니다.

넣으면 좋은 것:
- 기존 이력서 / 자기소개서 (PDF, docx, 텍스트 아무거나)
- 프로젝트 보고서, 발표자료, 회고 메모, README
- 결과 화면 스크린샷, 다이어그램
- GitHub 저장소 링크, 배포 주소 (`links.txt`에 적어두기)
- 대충 쓴 메모도 OK — "이거 했고, 이게 힘들었고, 결과는 이랬음" 수준이면 충분

프로젝트별로 하위 폴더를 만들어 넣으면 묶기가 더 정확해집니다 (예: `inbox/쇼핑몰-프로젝트/`).

이 폴더는 `.gitignore`에 포함되어 공개 저장소에 올라가지 않습니다.
